Oneiria

Guide de test

Quatorze scénarios, dans l’ordre. Les vérifications marquées d’une pastille sont exécutées automatiquement au chargement de cette page, sur l’environnement réel de votre navigateur.

01 Ouvrir chaque destination

  1. Toucher tour à tour Univers, Raccontes, Décrit, Memory en bas de l’écran.
  2. À chaque fois, vérifier que l’écran change, que l’onglet actif passe au violet, et qu’aucun défilement horizontal n’apparaît.
  3. Sur l’Univers, ouvrir l’icône d’engrenage en haut à droite : les réglages et la confidentialité s’affichent.

02 Créer un rêve écrit et le retrouver

  1. Univers → Je me souviens d’un rêve.
  2. Écrire au moins une phrase, choisir une émotion, ajouter deux mots-clés séparés par une virgule.
  3. Enregistrer → l’écran Dessine s’ouvre.
  4. Toucher Passer le dessin → retour à l’Univers. La constellation du mot-clé est apparue, et le fragment est dans Derniers fragments.
  5. Onglet Memory → le rêve y est, avec sa date, son émotion et ses mots-clés.

03 Créer une entrée « Rêve oublié »

  1. Univers → Je ne m’en souviens plus.
  2. Une confirmation apparaît, puis une entrée datée « Rêve oublié » est créée et l’Univers réaffiche le ciel.
  3. La refaire le même jour : ONEIRIA demande si vous voulez vraiment en ajouter une seconde.

04 Dictée et mode manuel

  1. Onglet Décrit. Lire le message sous le cercle.
  2. Si le cercle est actif : appuyer, autoriser le microphone, parler. La transcription s’écrit pendant la dictée.
  3. Appuyer sur Arrêter l’écoute, corriger le texte à la main si besoin.
  4. Si le cercle est désactivé : c’est que le navigateur ne propose pas la reconnaissance vocale. ONEIRIA ne l’active pas et vous le dit. Touchez le champ de transcription : sur iPhone, l’icône microphone du clavier iOS permet de dicter, et le texte arrive normalement dans le champ.

05 Dessiner : couleur, gomme, annulation

  1. Ouvrir un rêve depuis Memory ou créer un rêve neuf pour arriver sur Dessine.
  2. Tracer un trait avec le doigt (ou la souris).
  3. Choisir une autre couleur dans la palette, tracer un second trait.
  4. Passer en Gomme, frotter sur une partie du dessin : seule cette partie disparaît.
  5. Toucher Annuler : le dernier trait de gomme disparaît, le reste reste intact.
  6. Changer l’épaisseur (Fin / Moyen / Épais) et vérifier que le trait suivant est plus large ou plus fin.

06 Sauvegarder un dessin et vérifier l’association

  1. Toucher Garder le dessin.
  2. Dans Memory, ouvrir le rêve : la vignette du dessin apparaît dans la carte et en grand dans la fiche détail.
  3. Ouvrir un autre rêve dessiné : chaque dessin reste attaché à son propre rêve, jamais décalé.

07 Fermer puis rouvrir : persistance

  1. Fermer complètement l’onglet (ou l’application installée) puis la rouvrir.
  2. Tous les rêves et tous les dessins sont toujours là.
  3. Réglages → la ligne de stockage indique la base locale active et l’espace utilisé.

08 Modifier un rêve

  1. Ouvrir un rêve → Modifier.
  2. Changer le titre et le texte du premier fragment → Sauvegarder.
  3. Le titre mis à jour apparaît dans la fiche, dans Memory et dans Derniers fragments.

09 Ajouter un fragment à un rêve existant

  1. Ouvrir un rêve → Ajouter un fragment.
  2. Écrire la suite, ajouter un mot-clé, valider.
  3. Vérifier que le premier récit est toujours là, sous la mention « Fragment original », et que le nouveau figure dessous avec sa date propre.

10 Recherche et filtres

  1. Memory → taper un mot présent dans un rêve. La liste se réduit.
  2. Effacer la recherche avec la croix du champ.
  3. Tester les filtres Tous, Écrits, Racontés, Oubliés, Avec dessin.
  4. Depuis l’Univers, toucher une bulle de constellation : Memory s’ouvre filtré sur ce thème, avec un moyen de le retirer.

11 Exporter puis réimporter du JSON

  1. Réglages → Exporter en JSON. Un fichier oneiria-AAAAMMJJ-HHMM.json est téléchargé.
  2. Modifier un rêve pour créer une différence, ou supprimer l’application et la réinstaller.
  3. Réglages → Importer un fichier JSON → choisir le fichier exporté.
  4. Confirmer : les rêves sont ajoutés, rien n’est effacé, et les dessins reviennent avec leurs rêves.

12 Supprimer une entrée

  1. Ouvrir un rêve → Supprimer ce rêve.
  2. Un dialogue demande confirmation : annuler d’abord pour vérifier que rien ne disparaît.
  3. Recommencer et confirmer : la carte quitte Memory et Univers immédiatement.

13 Affichage en largeur iPhone

  1. Tourner l’iPhone en portrait et parcourir les quatre écrans.
  2. Aucun défilement horizontal, aucun texte coupé, les boutons restent larges sous le pouce.
  3. Ajouter l’app sur l’écran d’accueil (Safari → Partager → Sur l’écran d’accueil) : elle s’ouvre en plein écran, sans barre d’adresse.

14 Aucun bouton décoratif

  1. Chaque bouton rencontré doit produire un effet visible : navigation, enregistrement, ouverture d’une feuille, confirmation, ou message explicite.
  2. Les seuls retours acceptables sont un message clair : « Aucun trait à annuler », « Le dessin est déjà vide », etc.
  3. En cas de doute, toucher le bouton et vérifier qu’il se passe quelque chose — jamais un silence.

Ce que ce guide ne peut pas valider à ma place

La reconnaissance vocale selon la version d’iOS, les zones de sécurité autour de l’encoche et de la barre d’accueil, l’installation sur l’écran d’accueil, la fluidité réelle des animations et la limite de stockage de Safari ne se jugent que sur un appareil physique. Les tests automatiques ci-dessus portent sur les capacités du navigateur, pas sur le confort d’usage.
